# Data — provenance and layering

## Source

All price data is from **Agmarknet** (Government of India, Directorate of
Marketing & Inspection): <https://agmarknet.gov.in>. The specific report is
**"Date Wise Prices for Specified Commodity"**, downloaded one month at a time.

| Query parameter | Value |
|---|---|
| Commodity | Onion |
| State/UT | Maharashtra |
| Period | June 2024 – June 2026 (25 monthly exports) |
| Format | CSV (block-structured: market name as header rows) |

**Note:** August 2024 is absent from the source exports — a genuine gap, not a
processing loss. It is carried through the pipeline as missing, never filled.

## Layering (numbered, so the flow is obvious and immutable-source is protected)

```
data/
  01_source/     Raw Agmarknet exports, exactly as downloaded. NEVER written to.
  02_interim/    Parsed flat tables: daily_prices.csv, mandis.csv, coverage.csv
                 (grain: mandi x date x variety). Regenerated by parse_agmarknet.py.
  03_processed/  mandi.db (SQLite) + cleaned CSVs. Regenerated by the pipeline;
                 the .db is a build artefact and is git-ignored.
```

Everything below `01_source/` is reproducible: delete `02_interim/` and
`03_processed/` and run `python src/run_pipeline.py` to rebuild them.

## Units

- **Prices** — ₹ per quintal (min, max, modal).
- **Arrivals** — the source reports **metric tonnes**; the parser converts to
  **quintals** (×10) so every figure in the project is per-quintal.

## Key transformations applied at parse time

1. Market-name header rows walked into a proper `mandi` column.
2. Arrivals converted tonnes → quintals.
3. Market names canonicalised; stable IDs assigned by sorted canonical name.
4. Exact duplicate rows (a re-downloaded February 2025 export) dropped.
